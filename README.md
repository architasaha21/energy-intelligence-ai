# AI Energy Intelligence

AI agent layer for a Climate and Energy Optimization system.

This project consumes energy forecasts generated by the
Energy Forecasting ML service and converts them into:

- Energy analysis
- Peak-period identification
- Anomaly detection
- Energy-saving recommendations
- Intervention simulations
